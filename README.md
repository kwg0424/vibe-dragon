# DragOn - 우클릭·복사 허용

사이트별로 우클릭·드래그 선택·복사 차단을 해제하는 Edge 확장 (MV3).

**설치:** [Microsoft Edge 추가 기능](https://microsoftedge.microsoft.com/addons/detail/igcfaanbbnicppaialibgilpaooejaaf)

## 설정 저장 위치 (옵션 페이지 → 설정 저장 위치)
| 방식 | 저장 위치 | 다른 PC와 공유 |
|---|---|---|
| 이 브라우저에 저장 (기본) | `chrome.storage.sync` | Edge 계정 동기화 (확장 동기화 켜짐일 때) |
| 서버(WebDAV) 동기화 | `chrome.storage.local` + 내 WebDAV 서버 파일 | 같은 주소·아이디·비밀번호를 넣은 PC |

- 처음에는 묻지 않고 브라우저에 저장한다. 서버 동기화는 필요할 때 옵션 페이지에서 연결.
- WebDAV 인증은 아이디·비밀번호 (`Authorization: Basic`), `https://` 주소만 허용 (개발용 localhost 제외). 주소는 폴더까지만 입력 (`https://my-server/folder`)
- 저장된 비밀번호는 옵션 페이지로 보내지도, 다시 표시하지도 않는다 (변경할 때만 새로 입력, 비워 두면 그대로)
- 1.4.x 의 토큰 설정은 동기화 시 "접속 정보를 다시 입력하세요" 로 안내. 다시 연결하면 이 기기 목록을 새 파일로 올린다(서버에 이미 있으면 합침)
- 서버 파일 이름은 아이디·비밀번호에서 PBKDF2(600k)로 만든 32자리 16진수, 내용은 아이디·비밀번호로 암호화(AES-256-GCM).
  TapCode 와 같은 형식이라 [TapCode 의 WebDAV 서버](https://github.com/kwg0424/vibe-tabcode/tree/main/server)를 그대로 쓸 수 있고,
  같은 폴더·같은 계정이어도 파일 이름이 달라 서로 덮어쓰지 않는다.
- 서버 모드에서 사이트를 추가·변경·삭제하면 바로 서버에 저장한다 (연달아 바꾸면 한 번으로 묶음).
  저장이 실패하면 이 기기에는 남기고 옵션의 동기화 버튼에 빨간 점, 팝업에 실패 원인을 표시한다. 다음 변경이나 동기화 때 함께 올린다.
  다른 PC 변경은 옵션의 "동기화" 버튼이나 다음 저장 때 받는다. 연결할 때는 바로 한 번 동기화한다.
- 연결(해지 후 다시 연결 포함)할 때 서버에 이 기기와 다른 목록이 있으면 TapCode 처럼 묻는다:
  서버 목록으로 덮어쓰기 / 이 기기 목록을 서버에 올리기 / 취소. 목록이 같거나, 서버 파일이 없거나, 한쪽이 비어 있으면
  묻지 않는다 (이 기기가 비었으면 서버 목록을 가져오고, 서버가 비었으면 이 기기 목록을 올림).
- 마지막 동기화가 하루를 넘으면 브라우저 시작·페이지 로드 때 자동으로 한 번 동기화한다 (alarms 권한 없음).
  자동 동기화가 실패하면 수동 동기화가 성공할 때까지 자동으로 다시 시도하지 않는다 (옵션에 표시).
- 서버와 이 기기 양쪽이 바뀌었으면 묻지 않고 합친다: 양쪽 사이트를 모두 남기고, 같은 사이트는 이 기기 설정을 쓴다.
  한쪽만 바뀌었으면 삭제도 그대로 반영되지만, 양쪽이 바뀐 상태에서 한쪽이 지운 사이트는 다시 생긴다.
- 우클릭·복사와 강력 모드를 둘 다 끄면 그 사이트는 목록에서 빠진다.
- "브라우저 저장으로 전환"은 지금 목록을 브라우저 저장으로 옮기고 연결을 끊는다. 서버 파일은 남는다.
- 서버 모드에서는 `chrome.storage.sync` 를 건드리지 않는다 (브라우저 저장을 쓰는 다른 PC의 목록 보호).

## 테스트

```
node test/run.mjs
```
동기화 로직(생성·가져오기·자동 합치기·삭제 반영·손상 파일·계정별 파일·인증 실패·https 강제)을 테스트용 WebDAV 서버로 확인한다.

## 개발용 설치
`edge://extensions` → 개발자 모드 → 압축 풀린 확장 로드 → 이 폴더 선택
